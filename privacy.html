Privacy Policy

Last updated November 21, 2026

This policy covers the private tools Nathan Langley uses to manage his own YouTube channels (the "Render Distance uploader" Google API project). The tools are not offered to the public.

What the tools access

With the channel owner's permission, granted through Google's sign-in screen, the tools use the YouTube Data API and YouTube Analytics API to upload and schedule videos, set thumbnails, and read channel and video statistics. They access only channels owned by Nathan Langley.

How data is used and stored

Statistics and authorization tokens are stored only on Nathan Langley's own computers and used only to manage and analyse his own channels. No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Stored tokens are deleted when access is revoked.

Third-party terms

These tools use YouTube API Services. By using them you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
